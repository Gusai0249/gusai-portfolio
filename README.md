# Gusai Mohamed Portfolio

A static, responsive portfolio website for free hosting.

## Publish with GitHub Pages

1. Create a GitHub account at https://github.com/ if you do not have one.
2. Create a new **public** repository named `gusai-portfolio`.
3. Upload everything inside this folder (including `index.html`, `styles.css`, and `assets/`).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to deploy. Your website URL will usually look like:
   `https://YOUR-USERNAME.github.io/gusai-portfolio/`

## Before publishing

- Replace the Behance URL in `index.html` with your actual profile link.
- Confirm you have permission to publish client or organization work.
- Replace any placeholder wording and check all project details.
